# Схема базы данных

## Сущности и связи
1. **roles** — роли в системе (elderly, volunteer, coordinator, admin).
2. **users** — учётные записи пользователей.
3. **elderly_profiles** — дополнительная информация о пожилом человеке (адрес, координаты, год рождения, мобильность).
4. **volunteer_profiles** — профиль волонтёра (статус верификации, рейтинг, карма/баллы, координаты, радиус помощи).
5. **categories** — категории помощи (продукты, медикаменты, быт, техника, сопровождение, общение).
6. **help_requests** — заявки на помощь (подопечный, назначенный волонтёр, статус, секретный код, геолокация).
7. **chat_messages** — сообщения в рамках активной заявки.
8. **educational_materials** — база знаний (памятки, аудиоуроки, видеоматериалы).
9. **fraud_alerts** — оперативные предупреждения о мошенниках от соцслужб.
10. **volunteer_achievements** — достижения и награды волонтёров.
