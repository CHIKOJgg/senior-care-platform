# ADR-0015. Keyword-антифрод с необязательным OpenRouter AI и fallback

- **Статус:** Принято
- **Дата:** 2026-11-22
- **Категория:** Безопасность
- **Связанные ADR:** [ADR-0005](0005-hmac-auth-and-rate-limiting.md), [ADR-0007](0007-aes256gcm-and-data-masking.md)

## Контекст

Пожилые пользователи часто сталкиваются с телефонными и SMS-мошенниками. Проверка должна работать сразу, без обязательных внешних API и без задержки, но при наличии ключа может использовать более гибкий языковой анализ. Сервис не должен раскрывать персональные данные и не должен падать при недоступности AI-провайдера.

## Решение

`AntiFraudService::analyze()` использует двухуровневую схему:

1. Если задан `OPENROUTER_API_KEY`, текст отправляется в OpenRouter.
2. При ошибке, таймауте или некорректном ответе выполняется автоматический fallback на keyword-анализ.
3. Без ключа всегда используется keyword-анализ.

Параметры:

- `OPENROUTER_API_KEY` — включает AI-режим;
- `OPENROUTER_MODEL` — по умолчанию `openai/gpt-4o-mini`;
- `OPENROUTER_BASE_URL` — по умолчанию `https://openrouter.ai/api/v1`;
- таймаут запроса 20 секунд, connect timeout 8 секунд.

Ответ имеет единый контракт:

```json
{
  "risk_level": "danger|warning|safe",
  "summary": "краткое объяснение",
  "danger_matches": [],
  "warning_matches": []
}
```

Keyword-база содержит типовые фразы: код из СМС, CVV, номер карты, «безопасный счёт», звонок из мессенджера, проверка счётчика и другие.

Эндпоинт: `POST /api/antifraud/check`.

## Обоснование

1. Keyword-анализ работает offline и не требует затрат.
2. AI-режим подключается одной переменной окружения.
3. Fallback сохраняет работоспособность при сбое провайдера.
4. Единый ответ упрощает UI и тесты.
5. Пользователь получает понятное объяснение риска, а не только флаг.

## Последствия

### Положительные

- Проверка доступна без внешних ключей.
- AI можно включить без изменения кода.
- Сбой OpenRouter не блокирует антифрод.
- Результат пригоден для озвучивания и крупных баннеров.

### Отрицательные / риски

- Keyword-анализ не понимает сложные перефразирования.
- При включённом AI текст проверки передаётся третьей стороне.
- Нет гарантии качества и доступности OpenRouter.
- Нет кэширования и дедупликации запросов.
- AI-ответы требуют валидации схемы.

## Альтернативы

| Альтернатива | Почему не выбрана |
|---|---|
| Только keywords | Дешево, но ограничено шаблонами |
| Только AI | Зависимость от сети, ключа и оплаты |
| Локальная модель | Нужны GPU/CPU и обслуживание |
| Сторонний антифрод-сервис | Стоимость и передача данных |
