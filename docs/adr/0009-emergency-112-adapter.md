# ADR-0009. Адаптер МЧС 112 и устойчивая очередь SOS

- **Статус:** Принято
- **Дата:** 2026-11-22
- **Категория:** Интеграции
- **Связанные ADR:** [ADR-0006](0006-zero-composer-custom-libraries.md), [ADR-0010](0010-observability-stack.md), [ADR-0014](0014-web-speech-and-audio-api.md)

## Контекст

Кнопка SOS должна мгновенно создавать приоритетный инцидент, уведомлять координатора и, при наличии шлюза, передавать вызов в МЧС 112. Внешний шлюз может быть недоступен, но сигнал нельзя терять. Интеграция должна быть заменяемой и тестируемой без реального API.

## Решение

### Модель

SOS хранится в `sos_alerts` со статусом `ACTIVE`, `priority=0`, координатами, адресом и причиной. Координатор видит активные вызовы через `/api/sos/active` и разрешает их через `/api/sos/{id}/resolve`.

### Адаптер

`MchsEmergencyAdapter` реализует `EmergencyAlertAdapterInterface`:

- провайдер `EMERCOM_112_BY`;
- квитанция `EMERCOM-112-BY-YYYY-XXXX`;
- назначенный расчёт и ETA;
- проверка формата квитанции;
- логирование отправки;
- offline-очередь при имитации сетевого сбоя.

### Поток

1. `POST /api/sos`.
2. Координаты из запроса или профиля подопечного.
3. Создание `sos_alerts` с приоритетом 0.
4. Вызов адаптера.
5. Сохранение `emercom_ticket_id`.
6. Отображение баннера и сирены у координатора.
7. Разрешение инцидента.

## Обоснование

1. Изоляция внешнего шлюза.
2. Локальная фиксация вызова даже при сбое сети.
3. Приоритет 0 отделён от обычных заявок.
4. Правдоподобный контракт для демонстрации и тестов.
5. Аудит через `Logger::security`.

## Последствия

### Положительные

- SOS работает без внешнего API.
- Легко подключить реальный шлюз.
- Координатор видит квитанцию и статус.
- Сбой сети не приводит к потере инцидента в рамках процесса.

### Отрицательные / риски

- Offline-очередь хранится в памяти PHP-процесса.
- Реальная передача в 112 не выполняется.
- Нет идемпотентности и автоматического retry.
- Статус `DISPATCHED` является локальным.
- Адрес и координаты попадают в security-лог.

## Альтернативы

| Альтернатива | Почему не выбрана |
|---|---|
| HTTP-вызов 112 из контроллера | Нет публичного API и плохая тестируемость |
| SMS-шлюз | Платно и не даёт квитанцию |
| Redis/RabbitMQ | Избыточная инфраструктура для текущего масштаба |
| Только запись в БД | Нет контракта с внешней службой |
