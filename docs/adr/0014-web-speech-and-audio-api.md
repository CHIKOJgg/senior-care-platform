# ADR-0014. Web Speech API и Web Audio API для доступности

- **Статус:** Принято
- **Дата:** 2026-11-22
- **Категория:** Frontend
- **Связанные ADR:** [ADR-0002](0002-vanilla-js-frontend-wcag.md), [ADR-0009](0009-emergency-112-adapter.md)

## Контекст

Пожилым пользователям сложно набирать текст, читать мелкие инструкции и быстро находить SOS в стрессовой ситуации. Нужны голосовой ввод, озвучивание интерфейса и громкий сигнал для координатора без установки приложений и без серверных затрат на STT/TTS.

## Решение

Используются нативные браузерные API.

### Web Speech API

`public/js/speech.js`:

- `SpeechRecognition` / `webkitSpeechRecognition` для распознавания речи;
- `lang='ru-RU'`, короткие сессии, без промежуточных результатов;
- результат подставляется в заявку или поле антифрод-проверки;
- `SpeechSynthesis` для озвучивания страницы, предупреждений и памяток;
- голосовые команды SOS («помощь», «тревога», «SOS») вызывают `triggerSos`;
- при отсутствии API остаётся текстовый ввод.

### Web Audio API

В `public/js/app.js`:

- `AudioContext` / `webkitAudioContext`;
- `OscillatorNode` с попеременными частотами;
- `GainNode` для плавного звука;
- сирена включается при активном SOS и отключается координатором.

### Доступность

- крупные таргеты и `aria-label`;
- `aria-live` для экстренных сообщений;
- текстовые дубли иконок;
- кнопка «Озвучить страницу»;
- `Alt+S` останавливает речь.

## Обоснование

1. Нет серверных затрат на STT/TTS.
2. Аудио не хранится на сервере.
3. Работает в браузере телефона или планшета.
4. Нативная поддержка русского языка.
5. Сирена синтезируется без аудиофайлов.

## Последствия

### Положительные

- Заявку можно надиктовать вместо набора.
- Слабовидящий пользователь слышит экран и предупреждения.
- Координатор замечает SOS по звуку.

### Отрицательные / риски

- Поддержка браузеров неравномерна.
- Нужен HTTPS или localhost для микрофона.
- Пользователь может запретить доступ к микрофону.
- Chrome может обрабатывать речь через облако вендора.
- Web Speech может не работать без сети.
- Автовоспроизведение звука требует жеста пользователя.
- Точность распознавания зависит от речи и шума.

## Альтернативы

| Альтернатива | Почему не выбрана |
|---|---|
| Серверный Whisper | GPU/CPU, стоимость и передача аудио |
| Облачные TTS/STT | API-ключи, задержка и приватность |
| Записанные аудиофайлы | Хостинг, форматы и автозагрузка |
| Мобильное приложение | Высокий порог для пожилых |
| Только текст | Не решает проблему зрения и тремора |
