# Модульная верификация волонтёров, модерация ТЦСОН и цифровые бейджи с QR-кодом
## Цифровая идентификация и очная валидация добровольцев

### 1. Модульная архитектура адаптеров идентификации
Для обеспечения доверия пожилых граждан к волонтёрам система реализует модульный конвейер проверки личности через интерфейс `IdentityProviderInterface`:
- `getProviderName(): string` — имя шлюза (`MSI_BELARUS`, `GOSUSLUGI_ESIA`).
- `verifyIdentity(string $personalNumber, array $context): array` — синхронная верификация с маскированием ПД.
- `authenticate(array $credentials): array` — аутентификация в ЕСИА / МСИ.

---

### 2. Адаптер МСИ Республики Беларусь (Межбанковская система идентификации)
Адаптер `MsiIdentityAdapter` валидирует 14-значный личный номер паспорта гражданина Республики Беларусь:
- Регулярное выражение: `/^[1-6]\d{6}[A-Z]\d{3}[A-Z]{2}\d$/`.
- **Семантика полей**:
  - Индекс 0: пол и век (1 — муж., XIX в.; 2 — жен., XIX в.; 3 — муж., XX в.; 4 — жен., XX в.; 5 — муж., XXI в.; 6 — жен., XXI в.).
  - Индексы 1–6: дата рождения (ДДММГГ). Проверяется через `checkdate()`.
  - Индекс 7: код региона (A — г. Минск, B — Брестская обл., C — Витебская обл., E — Гомельская обл., K — Гродненская обл., M — Могилевская обл., H — Минская обл.).
  - Индексы 11–12: тип документа (`PB` — паспорт РБ, `BA` — лицо без гражданства, `BI` — вид на жительство).
- **Маскирование по Закону РБ № 99-З**:
  - Исходный: `3010190A001PB5` $\to$ Маскированный: `3010190A***PB5`.
  - В БД сохраняется SHA-256 хеш идентификатора и защищённый токен верификации (`kyc_msi_...`).

### 3. Адаптер ЕСИА / Госуслуги РФ (СНИЛС)
Адаптер `GosuslugiIdentityAdapter` валидирует 11-значный номер страхового свидетельства (СНИЛС):
- Формат: `XXX-XXX-XXX YY` или 11 цифр подряд.
- **Взвешенный алгоритм контрольной суммы по модулю 101**:
  $$\text{Sum} = \sum_{i=1}^{9} d_i \cdot (10 - i)$$
  - Если $\text{Sum} < 100 \implies \text{check} = \text{Sum}$.
  - Если $\text{Sum} \in \{100, 101\} \implies \text{check} = 0$.
  - Если $\text{Sum} > 101 \implies \text{rem} = \text{Sum} \pmod{101}$; если $\text{rem} < 100 \implies \text{check} = \text{rem}$; если $\text{rem} \in \{100, 101\} \implies \text{check} = 0$.
  - Специальное исключение: номера $\le 001001998$ не подлежат проверке контрольной суммы (исторические номера).
- Маскирование: `***-***-445 95`.

### 4. Консоль модерации волонтёров ТЦСОН
- Очередь кандидатов доступна координаторам по адресу `GET /api/coordinator/volunteers/pending`.
- Проверка включает:
  1. Личные документы (паспорт сверен с государственной базой).
  2. Справка об отсутствии судимости (`police_clearance_status`: `CLEAN` / `NOT_SUBMITTED`).
- Действия координатора:
  - Утверждение: `POST /api/coordinator/volunteers/{id}/verify` $\to$ статус `VERIFIED` (`is_verified = 1`), генерация цифрового бейджа.
  - Отклонение: `POST /api/coordinator/volunteers/{id}/reject` с обязательным указанием причины $\to$ статус `REJECTED`, блокировка всех активных бейджей.

### 5. Динамический цифровой бейдж волонтёра (HMAC-SHA256)
- **Токен динамического бейджа**:
  $$\text{Token} = \text{Base64Url}(\text{Payload}) \,\|\, '.' \,\|\, \text{Base64Url}(\text{HMAC-SHA256}(\text{Payload}, K))$$
- **Время жизни токена (TTL)**: ровно 3600 секунд (1 час). По истечении часа токен становится недействительным и требует обновления из личного кабинета волонтёра.
- **Payload**:
  - `vid`: идентификатор пользователя.
  - `bid`: номер аккредитации (`BY-MSK-SOV-2026-XXXX`).
  - `name`: сокращённое имя (`Алексей С.`).
  - `org`: "ТЦСОН Советского района г. Минска".
  - `status`: "VERIFIED".
  - `iat`: время выпуска.
  - `exp`: время истечения ($iat + 3600$).
- **Криптографическая верификация**:
  - Защита от атак по времени через `hash_equals()`.
  - Допуск рассинхронизации часов до 60 секунд.
  - Мгновенная проверка актуального статуса волонтёра в SQLite (отзыв действует незамедлительно даже при валидной криптографической подписи).

### 6. Векторный генератор SVG QR-кода на чистом PHP (ISO/IEC 18004)
Генерация QR-кода реализована в классе `BadgeService` без сторонних Composer-библиотек:
- Стандарт: ISO/IEC 18004:2015.
- Режим: Byte mode (индикатор `0100`).
- Уровень коррекции ошибок: Level L (7% восстановления данных).
- Конечное поле Галуа $GF(2^8) = GF(256)$ с неприводимым полиномом $x^8 + x^4 + x^3 + x^2 + 1$ (`0x11D`).
- Расчёт кодовых слов Рида-Соломона и блочное перемежение.
- Применение стандартной маски Mask 0 (код формата `0x77C4`).
- **Оптимизированный рендеринг Run-Length в SVG**: последовательные черные модули одной строки объединяются в непрерывные горизонтальные прямоугольники `<path d="M x,y h L v1 h -L z"/>`, что уменьшает размер SVG в 4–5 раз.
- Соответствие политике Zero-Emoji: 100% векторная графика без смайликов и растровых артефактов.

### 7. Общедоступная страница проверки бейджа (`public/verify.php`)
- Доступна подопечным и родственникам по ссылке из QR-кода без требования авторизации.
- Отображает официальный геральдический знак ТЦСОН, статус аккредитации, маскированное имя добровольца (`Алексей С.`) и номер бейджа.
- При сканировании просроченного или отозванного бейджа выводит высококонтрастный красный баннер с предупреждением не впускать постороннего в квартиру и телефоном дежурной службы ТЦСОН.
