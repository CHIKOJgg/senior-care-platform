# Спецификация GPS-геозонирования, безопасности присутствия и антифрод-защиты
## Реализация протокола Proof-of-Presence в платформе «ЗаботаРядом»

### 1. Математическая модель формулы Haversine и геозонирование
Для предотвращения фиктивных закрытий заявок недобросовестными исполнителями и обеспечения гарантии физического визита волонтёра к подопечному платформа реализует криптографически и математически выверенный протокол **Proof-of-Presence** на основе формулы **Haversine**.

#### 1.1. Константы и математические соотношения
- Принятый средний радиус Земли: $R_{\text{km}} = 6371.0$ км ($R_{\text{meters}} = 6371000.0$ м).
  $$R_{\text{meters}} = 6371000.0 \text{ м}, \quad R_{\text{km}} = 6371.0 \text{ км}$$
- Преобразование географических координат (широта $\phi$, долгота $\lambda$) в радианы:
  $$\Delta \phi = \frac{\pi}{180} (\phi_2 - \phi_1), \quad \Delta \lambda = \frac{\pi}{180} (\lambda_2 - \lambda_1)$$
- Формула гаверсинуса центрального угла:
  $$a = \sin^2\left(\frac{\Delta \phi}{2}\right) + \cos\left(\frac{\pi}{180} \phi_1\right) \cdot \cos\left(\frac{\pi}{180} \phi_2\right) \cdot \sin^2\left(\frac{\Delta \lambda}{2}\right)$$

#### 1.2. Численная стабилизация и защита от потери точности (Clamping)
В вычислительных системах с плавающей точкой стандарта IEEE 754 при обработке антиподальных координат (например, $[0, 0] \leftrightarrow [0, 180]$) значение $a$ может незначительно превысить $1.0$ или уйти ниже $0.0$. Для предотвращения ошибок вычисления `NaN` в функциях $\sqrt{a}$ и $\text{atan2}$ применяется строгое ограничение диапазона:
$$a_{\text{clamped}} = \max(0.0, \min(1.0, a))$$

Вычисление углового расстояния и итоговой дистанции:
$$c = 2 \cdot \mathrm{atan2}\left(\sqrt{a_{\text{clamped}}}, \sqrt{1.0 - a_{\text{clamped}}}\right)$$
$$d_{\text{meters}} = \mathrm{round}(R_{\text{meters}} \cdot c, 2)$$

#### 1.3. Порог геозоны (Geofence Threshold)
Допустимый радиус присутствия волонтёра у дома подопечного составляет:
$$R_{\text{max}} = 150.0 \text{ м}$$
- Если $d \le 150.0$ м: проверка местоположения считается успешно пройденной.
- Если $d > 150.0$ м: сервер отклоняет операцию с HTTP 400 и выдаёт точные параметры расхождения:
  ```json
  {
    "error": "Волонтёр находится вне допустимой зоны (расстояние: 320 м > 150 м)",
    "actual_distance_meters": 320.45,
    "max_allowed_meters": 150.0
  }
  ```

### 2. Секретное проверочное слово и пайплайн нормализации
При создании каждой заявки система генерирует проверочное кодовое слово. Для максимальной доступности пожилым людям используется доброжелательный природный словарь (15 слов):
> «Василёк», «Ромашка», «Берёза», «Солнце», «Каштан», «Радуга», «Рябина», «Клён», «Ласточка», «Колосок», «Подснежник», «Улыбка», «Ручеёк», «Янтарь», «Дубрава».

#### 2.1. Алгоритм нормализации в `SecurityService::normalizeCode`
Для исключения ложных отклонений из-за опечаток, автозамены кавычек в мобильных клавиатурах и различий в букве «ё» код подвергается 5-этапной обработке:
1. `trim($code)` — отсечение начальных и концевых пробелов, табуляций и переносов строк.
2. `preg_replace('/^["\'«»`“”‘’]+|["\'«»`“”‘’]+$/u', '', $code)` — удаление любых видов кавычек (типографские «ёлочки», парные лапки, прямые кавычки).
3. Повторный `trim($code)`.
4. `mb_strtolower($code, 'UTF-8')` — приведение строки к нижнему регистру в кодировке UTF-8.
5. `str_replace('ё', 'е', $code)` — унификация букв «ё» и «е» (например, «Берёза» $\to$ «береза»).

Пример: ввод `  «Василёк»  ` эквивалентен эталонному `василек`.

### 3. Механизм защиты от подбора (5-Attempt Brute-Force Lockout)
Для предотвращения атак методом перебора секретного слова:
- Таблица `help_requests` содержит счётчик `failed_attempts INTEGER DEFAULT 0`.
- При каждой неудачной попытке ввода кода значение `failed_attempts` инкрементируется.
- Если `failed_attempts < 5`, возвращается ошибка HTTP 400 с количеством оставшихся попыток.
- При достижении 5 неудачных попыток (`failed_attempts >= 5`) заявка **безвозвратно блокируется**:
  - Все последующие запросы на завершение (даже с правильным кодовым словом) отклоняются сервером:
    `"Превышено максимальное количество попыток ввода секретного слова (5 попыток). Заявка заблокирована для проверки координатором."`
  - Разблокировка возможна только координатором ТЦСОН после очного выяснения обстоятельств.

### 4. Антифрод-мониторинг и эвристический анализ сообщений
Сервис `AntiFraudService` реализует автоматический поиск подозрительных паттернов социальной инженерии, направленных против пенсионеров:

- **Категория `danger` (критическая угроза мошенничества)**:
  - Паттерны: «код из смс», «смс-код», «код подтверждения», «три цифры на обороте», «cvv», «номер карты», «безопасный счёт», «следственный комитет», «депозит под высокий процент».
  - Действие: блокировка подозрительной активности, вывод крупного предупреждающего окна для подопечного с рекомендацией не сообщать коды и звонить в милицию (102).
- **Категория `warning` (повышенное внимание)**:
  - Паттерны: общение через внешние мессенджеры («вайбер», «viber», «телеграм», «telegram»), навязчивые предложения платных проверок счётчиков и фильтров для воды.
  - Действие: информирование подопечного и координатора.
